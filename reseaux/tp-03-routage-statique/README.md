
# TP 3 — Routage statique Cisco

## 🎯 Objectif

Configurer le routage statique entre plusieurs réseaux afin de permettre leur communication.

## 🛠️ Outils utilisés

- Cisco Packet Tracer
- Routeurs Cisco
- PC
- Câbles réseau

## 📚 Travail réalisé

- Configuration des interfaces des routeurs
- Attribution des adresses IP
- Configuration des routes statiques
- Vérification de la table de routage
- Test de communication avec `ping`

## 💻 Commandes principales

```text
show ip interface brief
show ip route
ping
ip route
